# Arquitetura-de-Dados-em-People-Analytics
Projeto ponta a ponta de People Analytics. Utilizei Python para gerar uma base sintética e estruturada em Star Schema (Fatos e Dimensões). No Power BI, criei um dashboard estratégico com métricas avançadas em DAX, como absenteísmo e turnover, aplicando boas práticas de Engenharia de Dados e simulando um ambiente corporativo real.
